# Evidence matrix

Requirement → responsible component → source → executable test → result.
Kind: **N** normative (specification), **U** upstream behaviour relied on
(gose/kryptos for the native backend, oidcc/jose for the alternate), **W** deliberate Warden policy stricter than upstream defaults.
Suites: `fast` (`scripts/check`), `keycloak`, `node`, `interop`
(`WARDEN_SUITE=<suite> gleam test`), `browser` (`scripts/browser-journey`),
`conformance` (`scripts/conformance`). Results are from the run recorded in
[PROGRESS.md](PROGRESS.md); nothing skipped is counted as a pass. Rows hold
for both backends unless a row names one (`WARDEN_BACKEND=native|oidcc`).
