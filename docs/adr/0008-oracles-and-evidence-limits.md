- **Decision:** retain pinned independent oracles, raw receipts and executable attack/lifecycle cases. Release acceptance requires current dependency review, selected conformance/interoperability, no unexplained differential or owned-facade failure, independent security review and release SBOM.

Unsigned-token modules were skipped because Warden refused none; RP logout required human review; third-party initiation failed in suite setup before any RP request. The old full finding tables are historical evidence rather than a current defect inventory.

BEAM inspection and whole-row rollback remain application operating responsibilities. Session clocks use later D20 wall-clock policy, superseding old F9/monotonic prose.
- **Prior validation attribution:** `f3847d1` recorded 209 core, 18 negative plus positive control, 13 consumer and six Relay recipe tests. This documentation migration does not rerun those suites or renew those historical security claims. The prior review reran local consumer/recipe tests only, without production provider or certification calls.
