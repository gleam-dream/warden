# Design coverage

The repository has one Warden context. [design/design.typ](design/design.typ) owns the system models and [design/CONTEXT.typ](design/CONTEXT.typ) owns canonical terms. Scope includes the complete retained protocol intent, not only exported functions. Section names below are stable owners; ADRs retain chronology and rationale.

No runtime part is intentionally out of scope. Generated `build/`, downloaded dependencies, private environment values and temporary design/context exports are not authored system scope. Raw evidence receipts remain bounded observations rather than an implementation approval. Later protocol families and unresolved cleanup, reconciliation and conformance questions remain visible in the native Pending updates ledger.
