# Attack matrix (gate V5b)

RFC 9700 threats plus callback, transport and refresh attacks. Each row names
the mitigating component and the executable test. Every row passes in the
recorded run ([PROGRESS.md](PROGRESS.md)); rows that depend on an
application duty say so.

| Threat                                                           | Mitigation                                                                                                  | Test(s)                                                                                                                                                  |
| ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Login CSRF / session fixation (RFC 9700 §4.7)                    | State bound to the transaction; browser-binding cookie required and compared in constant time               | Keycloak `invalid_binding_or_issuer_does_not_consume_the_login_test`; browser "callback without the browser binding"                                     |
| Authorization-code replay (RFC 6749 §4.1.2)                      | Store-atomic consumption before exchange; provider single use                                               | `racing_callbacks_consume_once_test`; Keycloak `replayed_callback_is_rejected_test`, 8-way race; browser replay                                          |
| Code injection (RFC 9700 §4.5)                                   | PKCE S256 per transaction; nonce per transaction                                                            | Keycloak `injected_code_is_rejected_by_pkce_test`                                                                                                        |
| PKCE downgrade (RFC 9700 §2.1.1)                                 | S256 required in metadata; oidcc plain fallback prevented; URL checked for Warden's own challenge           | `incompatible_providers_are_rejected_at_startup_test` (NoS256); P1                                                                                       |
| Mix-up (RFC 9700 §4.4, RFC 9207)                                 | `iss` response parameter compared; exact issuer in ID token; per-client issuer                              | Keycloak `invalid_binding…` (issuer mismatch/missing); `missing_issuer_parameter_follows_policy_test`; node `wrong_iss`; conformance `invalid-iss`       |
| Token substitution (another client's ID token)                   | Exact audience, `azp`, nonce                                                                                | node `wrong_aud`, `extra_aud`, `wrong_azp`; conformance `invalid-aud`                                                                                    |
| Nonce replay                                                     | Nonce per transaction, compared in constant time                                                            | node `wrong_nonce`, `missing_nonce`; conformance `nonce-invalid`                                                                                         |
| Algorithm confusion / `alg: none`                                | Configured allowlist (no HMAC, no `none`), intersected with metadata                                        | node `alg_none`, `hs256_confusion`, `hs256_client_secret`; conformance `idtoken-sig-none` (rejected → SKIPPED)                                           |
| Signature forgery / unknown keys                                 | oidcc verification; unknown-kid refresh; unusable keys ignored                                              | node `bad_signature`, `unknown_kid`, `no_kid_wrong_key`; `signing_key_rotation_refreshes_keys_test`; conformance `invalid-sig-rs256`, key rotation       |
| Encrypted unsigned ID token (GHSA-533g-4vf3-xwrj)                | oidcc 3.9.0; encryption disabled in narrowing                                                               | node `encrypted_unsigned`                                                                                                                                |
| Access-token hash substitution                                   | oidcc conditional `at_hash`                                                                                 | node `bad_at_hash`                                                                                                                                       |
| Redirect-URI manipulation (RFC 9700 §4.1)                        | One configured redirect URI, validated; exact reuse at exchange                                             | `redirect_uri_policy_test`; P1 (wrong redirect rejected by provider)                                                                                     |
| Open redirect via post-logout URI                                | Post-logout URI validated like redirect URIs                                                                | `logout_removes_custody_then_redirects_test`                                                                                                             |
| Duplicate / ambiguous callback parameters                        | Strict parser                                                                                               | `callback_parsing_table_test`, `callback_parser_is_total_test`, Keycloak malformed test                                                                  |
| Callback with foreign state or issuer burning a legitimate login | Mismatch never consumes                                                                                     | Keycloak `invalid_binding…` (legitimate callback completes afterwards)                                                                                   |
| Malicious discovery                                              | Exact issuer; incompatible metadata refused (PAR/JAR required, HS-only, no S256)                            | `incompatible_providers_are_rejected_at_startup_test`; conformance `discovery-issuer-mismatch`                                                           |
| SSRF via discovery, endpoints, JWKS, redirects                   | Destination policy on every resolved address, DNS pinned, no redirects, HTTPS only, optional host allowlist | `warden_http_test` (private, loopback, reserved, mixed, rebinding, allowlist, redirect); `loopback_provider_is_rejected_by_default_policy_test`          |
| Wrong-host / self-signed / expired TLS                           | Peer and hostname verification with explicit anchors                                                        | `warden_http_test` TLS cases                                                                                                                             |
| Oversized or endless responses                                   | Bounds before/while reading; deadline                                                                       | `warden_http_test` size, chunked, timeout cases                                                                                                          |
| Refresh-token replay after rotation (RFC 9700 §4.14)             | Reservation per generation; uncertain → quarantine; never resend                                            | `concurrent_refresh_sends_one_request_test`; `uncertain_and_invalid_refresh_outcomes_quarantine_test`; node lost response; Keycloak reuse detection (P1) |
| Refreshed identity substitution (OIDC Core §12.2)                | Continuity of issuer, subject, audience, azp, nonce, `auth_time`                                            | refresh continuity cases; conformance `refresh-token-invalid-issuer`, `-invalid-sub`                                                                     |
| Userinfo substitution                                            | Expected subject                                                                                            | `userinfo_requires_subject_continuity_test`; conformance `userinfo-invalid-sub`                                                                          |
| Secret leakage via errors, logs, telemetry                       | Closed classifications; transport strips provider bodies                                                    | `no_secret_reaches_errors_logs_or_telemetry_test`; `warden_oidcc_test`                                                                                   |
| Atom exhaustion (GHSA-mj35-2rgf-cv8p class)                      | Names allocated at startup; fixed parameter keys                                                            | `hostile_callbacks_create_no_atoms_test`                                                                                                                 |
| Pending-login flooding                                           | Store capacity                                                                                              | `pending_logins_are_bounded_test` (applications should also rate-limit login starts)                                                                     |
